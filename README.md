# Brian Hill Motors — website demo

**Preview only. Not a live dealer site.** Do not point a client domain at this repository.

Two colour treatments of the same build, for comparison:

- **Red** — https://dealersales.github.io/brianhillmotors-demo/
- **Blue** — https://dealersales.github.io/brianhillmotors-demo/blue/

## What this is

The new Digital Sales Consultants dealer template, re-skinned for **Brian Hill Motors**,
68 Bury New Road, Heywood OL10 4RF — built as a static export so it can be viewed without hosting.

- **60 vehicles** are the dealer's real stock, with their own photos, prices and specs.
- **Red `#ab2525`** is sampled from the JMC oval; **blue `#2c7eb2`** from the BHM oval.
- Every page is `noindex` and carries a "Demo preview" badge.
- Search and filter forms are inert — a static host cannot filter. Stock is paginated as separate pages.

## Not filled in

Finance APR and any representative example, warranty terms, unwatermarked photography, the dealer's
real logo, ICO registration number, Carro dealer ID, CodeWeavers key and analytics. The build makes no
claim about any of them.

## Maintenance

Static export of a PHP build; regenerate rather than edit here. Source and scripts live in the
`jmc-motors` project on Woody's Mac.
